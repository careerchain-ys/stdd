# 開発プロセスの改善の登録簿

開発プロセス（skill・agent・フック・検査スクリプト・規約・テンプレート）の**改善施策と効果測定の履歴**を持つ作業記録。
読み書きの手順は `measuring-dev-process` skill が持つ。

- **数字の正本は収集スクリプト**（`measuring-dev-process/scripts/collect.sh`）。ここに書くのは判定の根拠になった値だけで、
  同じ引数で回し直せば再現できる形（窓と引数）で残す。
- **施策の行は消さない。** 判定が変わったら追記する（効かなかった施策も、同じ案を再び出さないための記録になる）。
- 日付は GitHub のマージ日（UTC）。
