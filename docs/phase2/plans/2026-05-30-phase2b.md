## 実装スコープ

Phase 2-A 完了後の v0.1.0 公開準備として、ミニマム方針 (#1289, @yuki-sakaue) に沿って下記 4 領域を本 PLAN で対応する:

- **A. CLI 実装** — `npx create-stdd-project <name>` で `templates/minimal/` を展開する（Handlebars レンダリングは最小化、複雑な置換は行わない）
- **B. SECURITY.md** — 通報経路・SLA・サポート対象バージョンを日本語で明文化
- **C. 最小 examples 動作確認** — 展開先で `auto-implement` を手動 1 回通す（N=5 統計評価は廃止）
- **D. `skill-creator` / `security-scan` 最終扱い決定** — `docs/plugin-separation-policy.md` §5 を確定

旧 Phase 2-C は廃止し、本 Phase に統合した（#1293 コメント 4581180100 参照）。`nextjs-supabase-starter/` テンプレートは v0.2.0 以降に延期。

**変数化スコープ判断**（2026-05-30）: skill / agent / hook 内の `{{}}` 変数化（`user_app` / `admin_app` / `npx tsc --noEmit` 等のハードコード除去）は **Phase 3 (#1294) へ延期**。Phase 2-B では `.claude/` 配下を templates/minimal/ にそのままコピーし、利用者プロジェクトでは CLAUDE.md 経由でハードコード値を読み替える。v0.1.0 の動作にはこれで十分という判定。
