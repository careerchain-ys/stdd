# [サービス名] デザイン標準

> UI を持つ機能の実装・ワイヤーフレームが参照する SSoT。
> ベースとするデザインシステム: [getdesign(apple) / 自社 等]

## 1. デザイン原則

- **トーン＆マナー**: [例: 余白を活かしたミニマル / 情報密度より可読性を優先]
- **一貫性**: 同種の操作・状態は全画面で同じコンポーネント・トークンで表現する
- **アクセシビリティ**: コントラスト比 4.5:1 以上、キーボード操作・フォーカス可視を担保

## 2. デザイントークン

| 種別 | トークン | 値 |
| --- | --- | --- |
| Color | `color.primary` | #... |
| Color | `color.text` | #... |
| Color | `color.danger` | #... |
| Typography | `font.body` | [フォント / サイズ / 行間] |
| Typography | `font.heading` | [フォント / サイズ / 行間] |
| Spacing | `space.sm` / `space.md` / `space.lg` | 8 / 16 / 24px |
| Radius | `radius.md` | [角丸] |
| Shadow | `shadow.card` | [影] |

## 3. コンポーネント規約

- **ボタン**: 種別（primary / secondary / ghost）・状態（default / hover / disabled / loading）・サイズ
- **フォーム**: ラベル位置・必須表記・バリデーションエラーの表示位置（インライン）
- **テーブル / 一覧**: ゼブラ・ソート・空状態の表現
- **グラフ**: 共通の配色・凡例・ツールチップ方針（描画ライブラリは ARCHITECTURE 参照）

## 4. レイアウト原則

- **グリッド / ブレークポイント**: [例: 12 カラム / sm 640・md 768・lg 1024]
- **余白 / 階層**: セクション間 `space.lg`、要素間 `space.md` を基準とする
- **対象デバイス**: [PC 主体 / レスポンシブ要否]
